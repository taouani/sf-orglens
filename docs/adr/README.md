# Decision records

A decision record is one short file that states a decision, why it was made, and what it rules out. A change to
the architecture, the data model, the storage format or a public contract needs one.

The 27 decisions the project started from are listed in the decision log of the
[re-architecture plan](../plans/re-architecture-plan.md#decision-log). They are written out as individual records,
with a template and an index, in the second pull request of Phase 0.
