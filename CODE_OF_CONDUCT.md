# Code of Conduct

OrgLens adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. The full text at that address applies to this project and to everyone who takes part in it:
in issues, pull requests, discussions and any other project space.

In short: be respectful, assume good faith, give and accept feedback gracefully, and keep the focus on what is best
for the project and its users. Harassment, personal attacks and publishing other people's private information are
not acceptable.

## Reporting

If you experience or witness behaviour that goes against the code of conduct, report it privately to the
maintainers. Until the project has a dedicated contact address, use the private
[reporting form](https://github.com/taouani/sf-orglens/security/advisories/new) of this repository, which only the
maintainers can read. Reports are handled confidentially.

## Enforcement

The maintainers follow the enforcement guidelines of the Contributor Covenant 2.1: correction, warning, temporary
ban and permanent ban, depending on the seriousness of the behaviour.
