Usage: orglens source add [options] <name>

Adds a source to orglens.toml. Nothing is connected or read yet. Comments and
the layout of the file are kept.

Arguments:
  name                   a short name: lower-case letters, digits and hyphens

Options:
  --kind <kind>          the kind, required (choices: "org", "sandbox", "git")
  --description <text>   a note for people
  --org-id <id>          org, sandbox: the 15 or 18 character org id
  --login-url <url>      org, sandbox: the login URL, if it is not the default
  --sandbox-of <source>  sandbox: the org source it is a sandbox of
  --sandbox-name <name>  sandbox: the name of the sandbox
  --repo <folder>        git: the repository, relative to the workspace
                         (default: ".")
  --ref <ref>            git: the branch, tag or commit to read (default: the
                         working tree)
  --path <folder>        git: a folder of the repository that belongs to this
                         source; repeat for several
  --tracks <source>      git: the org or sandbox source this repository
                         describes
  -h, --help             show help and exit

Global Options:
  -V, --version          print the version and exit
  --json                 write the result as one line of JSON
  --workspace <folder>   the workspace folder (default: found from the current
                         folder upwards)
