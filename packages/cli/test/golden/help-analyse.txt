Usage: orglens analyse [options] <source>

Analyses the latest snapshot of a source again, from the files it holds: which
components they make up, and which component refers to which. The source is not
read. The analysis the snapshot had is replaced, and nothing else of the
snapshot changes. Use it after an update of OrgLens that analyses more, and for
a snapshot an older version took. A database that an older version wrote is
migrated first. The exit code is 5 if the snapshot is partial or its analysis is
incomplete.

Arguments:
  source                the name of the source

Options:
  --snapshot <number>   the snapshot to analyse (default: the latest)
  -h, --help            show help and exit

Global Options:
  -V, --version         print the version and exit
  --json                write the result as one line of JSON
  --workspace <folder>  the workspace folder (default: found from the current
                        folder upwards)
