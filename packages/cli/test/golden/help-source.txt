Usage: orglens source [options] [command]

Declares the sources of the workspace in orglens.toml.

Options:
  -h, --help            show help and exit

Global Options:
  -V, --version         print the version and exit
  --json                write the result as one line of JSON
  --workspace <folder>  the workspace folder (default: found from the current
                        folder upwards)

Commands:
  add [options] <name>  declare a source
  list                  list the declared sources
  remove <name>         remove the declaration of a source
