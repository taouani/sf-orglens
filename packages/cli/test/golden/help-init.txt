Usage: orglens init [options] [folder]

Makes a folder an OrgLens workspace: writes orglens.toml and creates the data
folder .orglens. In a folder that already has an orglens.toml, only what is
missing in .orglens is created.

Arguments:
  folder                the folder (default: the current folder)

Options:
  --name <name>         the label of the workspace (default: the name of the
                        folder)
  -h, --help            show help and exit

Global Options:
  -V, --version         print the version and exit
  --json                write the result as one line of JSON
  --workspace <folder>  the workspace folder (default: found from the current
                        folder upwards)
