Usage: orglens snapshot [options] <source>

Reads a source now, stores its metadata files as a new snapshot in the workspace
database, and analyses them: which components they make up, and which component
refers to which. Earlier snapshots are kept. The source is not changed. An org
or a sandbox is asked what it holds, and its components are retrieved in chunks,
which takes minutes. If that is interrupted, the next run continues the same
snapshot. OrgLens asks for metadata only, never for records. The exit code is 5
if the snapshot is partial or its analysis is incomplete: something could not be
read or analysed, and the output says what. It is 4 if the login is missing or
does not work or the org cannot be reached.

Arguments:
  source                the name of the source

Options:
  --restart             org, sandbox: give up a snapshot that was interrupted,
                        and take a new one
  -h, --help            show help and exit

Global Options:
  -V, --version         print the version and exit
  --json                write the result as one line of JSON
  --workspace <folder>  the workspace folder (default: found from the current
                        folder upwards)
