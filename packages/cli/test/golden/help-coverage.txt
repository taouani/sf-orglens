Usage: orglens coverage [options] <source>

Shows the latest snapshot of a source: the number of components per metadata
type, and everything that was left out or went wrong while it was taken. Reads
only.

Arguments:
  source                the name of the source

Options:
  --snapshot <number>   the snapshot to show (default: the latest)
  -h, --help            show help and exit

Global Options:
  -V, --version         print the version and exit
  --json                write the result as one line of JSON
  --workspace <folder>  the workspace folder (default: found from the current
                        folder upwards)
