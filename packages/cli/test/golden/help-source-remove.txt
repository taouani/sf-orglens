Usage: orglens source remove [options] <name>

Removes a source from orglens.toml. Every other line of the file is kept.
Snapshots already taken of the source stay in the database.

Arguments:
  name                  the name of the source

Options:
  -h, --help            show help and exit

Global Options:
  -V, --version         print the version and exit
  --json                write the result as one line of JSON
  --workspace <folder>  the workspace folder (default: found from the current
                        folder upwards)
