Usage: orglens [options] [command]

Local-first impact analysis for Salesforce orgs and repositories.

Options:
  -V, --version                print the version and exit
  --json                       write the result as one line of JSON
  --workspace <folder>         the workspace folder (default: found from the
                               current folder upwards)
  -h, --help                   show help and exit

Commands:
  init [options] [folder]      create a workspace
  source                       declare the orgs, sandboxes and repository
                               folders to read
  status                       show the workspace, its database and its sources
  snapshot <source>            read a source and store what it holds
  coverage [options] <source>  show what a snapshot holds and what it is missing
  doctor                       check that OrgLens can run here

Pre-release: the analysis commands are not available yet.
