Usage: orglens source check [options] <name>

For an org or a sandbox: finds the login, connects, and asks the org which org
it is. The login is a private key in the variables ORGLENS_JWT_<SOURCE>_... if
they are set, else the linked Salesforce CLI login, else the one Salesforce CLI
login of the declared org. For folders of a repository: reads everything a
snapshot would read. Nothing is stored and the source is not changed. The exit
code is 4 if the login is missing or does not work or the org cannot be reached,
and 5 if folders can be read only in part.

Arguments:
  name                  the name of the source

Options:
  -h, --help            show help and exit

Global Options:
  -V, --version         print the version and exit
  --json                write the result as one line of JSON
  --workspace <folder>  the workspace folder (default: found from the current
                        folder upwards)
